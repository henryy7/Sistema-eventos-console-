# Sistema de Eventos (Java, Console)
Aluno: Henry Gabriel

Protótipo em Java (POO) para cadastro de usuários e eventos, inscrição de usuários e consultas, executando no console.

## Como executar
1. Compilar:
   javac SistemaEventos.java
2. Executar:
   java SistemaEventos

## Funcionalidades
- Cadastro de usuário (nome, e-mail)
- Cadastro de evento (nome, data, local)
- Inscrição de usuário em evento
- Listagem de eventos por usuário
- Listagem de todos os eventos
