
# Sistema de Eventos (Console, Java)

Projeto acadêmico desenvolvido por **Henry Costa (@henryy7)** no curso de **Análise e Desenvolvimento de Sistemas (ADS) - USJT**.  
Este sistema é um protótipo criado para fins educacionais, aplicando conceitos de **programação orientada a objetos** e **persistência de dados**.

## ✨ Funcionalidades
- Cadastrar eventos (nome, descrição, local, categoria e data/hora)
- Listar todos os eventos
- Ver próximos eventos
- Confirmar presença em um evento (por ID)
- Filtrar por categoria (SHOW, ESPORTE, FESTA, CURSO, OUTROS)
- Gerar relatórios em texto (todos, futuros, participantes)
- Checar lembretes (eventos que acontecem na próxima 1 hora)
- Persistência em arquivo (`data/events.db`)

## 🚀 Como rodar

### Windows
1. Abra o **Prompt de Comando** na pasta do projeto.
2. Execute:
```
scripts\run_windows.bat
```

### Linux/Mac
1. Abra o **Terminal** na pasta do projeto.
2. Execute:
```
chmod +x scripts/run_linux_mac.sh
scripts/run_linux_mac.sh
```
